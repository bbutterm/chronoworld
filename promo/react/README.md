# Промо на React (альтернатива ролику)

Анимированная промо-страница Chronoworld: 35 с по кругу, вертикально 9:16 во весь экран телефона, на десктопе —
телефон по центру. React 18 + Framer Motion, сборка Vite в статику `dist/`. Та же анимация рендерится в mp4 для честного
сравнения с роликом `promo/video/chronoworld_promo_30s.mp4`.

Готовое:
- `out/chronoworld_react_30s.mp4` — рендер страницы: 1080×1920, 30 fps, H.264 (yuv420p, faststart) + AAC, 35 с.
- `dist/` (после `npm run build`) — страница, которую можно выложить как есть (относительные пути, base `./`).

## Как открыть и собрать

Из `promo/react` (своё `package.json`, `node_modules` не коммитятся):

```sh
npm install
npm run dev            # http://localhost:5260 — живой просмотр
npm run build          # статика в dist/ (≈ 100 КБ JS gzip + кадры WebP, грузятся по сценам)
npm run preview        # проверить dist на http://localhost:5261
```

Полезные адреса: `?t=12.3` — открыть на паузе в момент 12,3 с; `?render=1` — режим рендера (без кнопок и часов).
В консоли: `seek(t)` — перейти к моменту, `promo` — сцены и удары.

Ассеты уже лежат в `public/` (коммитятся). Пересобрать после новых кадров в `promo/shots`, `promo/branches`:
`python3 prepare_assets.py` (нужен Pillow и imageio-ffmpeg) — WebP 1080 и 720 px, карты RO из `assets/ui/cards`,
звуки m4a/ogg, трек «Backattack!!» (`music_battle_desert`) обрезан ровно на 35 с с затуханием.

## Рендер mp4

```sh
pip install imageio-ffmpeg            # ffmpeg
node render.mjs                       # vite build → out/chronoworld_react_30s.mp4 (≈ 5–10 мин)
node render.mjs frames 0.9,8.3        # отдельные кадры рендера → .work/preview
node render.mjs preview 390x844 1,4.2 # снимки живой страницы (с кнопками) нужного размера
```

Playwright — глобальный (`npm root -g`), Chromium из `PLAYWRIGHT_BROWSERS_PATH` (`playwright install` не запускать).
`dist` раздаётся `python3 -m http.server` (порт 5262, `PROMO_REACT_PORT`). `PROMO_BUILD=0` — не пересобирать,
`PROMO_CRF` — сжатие видео (по умолчанию 24: ≈ 16 МБ; больше — меньше файл). Звук mp4 собирает ffmpeg из тех же файлов и моментов, что играет страница.

Как это детерминировано: всё время ролика — один `MotionValue` (`src/timeline.js`), каждая анимация — функция
этого времени (`useTL`), пружины — генератор `spring` Framer Motion, вычисленный в момент t, частицы — хеш от
номера. Поэтому `window.seek(t)` всегда даёт один и тот же кадр; рендер ставит 1050 кадров по очереди.

1. 0–3 — логотип CHRONOWORLD по буквам с ударом и лучами, «Мир Ragnarok оживает», «idle-RPG прямо в Telegram».
2. 3–6,4 — «Ульта по касанию»: палец на портрете Вики, наезд камеры, «КРИТ!», плашка «Вика · Монахиня — Удар Асуры».

   вспышка по краям, тряска, «СБИТО!».
4. 9,6–12,4 — карта кампании (глава 10): «10 глав мира RO», подсветка сундука офлайн-наград, касание «Собрать».

6. 15,4–17,8 — сетка героев, счётчики «12 героев», «24 ветки», «6 классов · парень и девушка».
7. 17,8–20,4 — Таверна: касание «Призыв ×10», вспышка круга призыва, «3 одинаковые карты → редкость выше».
8. 20,4–24 — «Боссы глав и MVP»: Дракула, Фараон, Бафомет — по 1,2 с с наездом, рыком и красной вспышкой.

12. 31,2–35 — логотип, «Играй в Telegram», кнопка «Играть» (касание пальцем), затемнение и по кругу.

## Чем отличается от видео

- Интерактив: касание кадра — удар (цифра урона, крит, вспышка, тряска, звук); свайп вбок или ← → — соседняя
  сцена; полоска сцен сверху кликабельна; пауза (кнопка или пробел); кнопка «Играть» живая
  (`https://t.me/Chronoworldbot?startapp`) — и в углу всё время, и большая в финале.
- Наклон: на десктопе телефон поворачивается за мышью, на телефоне кадры и надписи сдвигаются от пальца
  (и от наклона устройства на Android) — параллакс.
- Текст — живой HTML со шрифтами Russo One и Rubik: чёткий на любом экране, не пережат кодеком.
- Кадры — во весь экран при любом соотношении (обрезка по фокусу кадра, без чёрных полос): 9:16, 9:19,5, десктоп.
- Вес: кадры WebP (720 px на обычных экранах, 1080 px на плотных), грузятся по сценам; звук — только после касания
  (браузеры не дают автозвук), музыка ≈ 0,4 МБ. Видео же весит МБ сразу и играет со звуком в ленте.
- Минусы: в ленты TikTok/Reels/Stories страницу не загрузить — для них mp4 (`render.mjs`); нужен браузер.

Файлы `src/`: `timeline.js` — время, пружины, удары (`IMPACTS`); `scenes.jsx` — сценарий; `components.jsx` — кадр,
надписи по буквам, плашки, касания, лучи, карты; `App.jsx` — сцена, касания, свайпы, кнопки; `audio.js` — музыка и
удары (Web Audio); `pointer.js` — наклон.
