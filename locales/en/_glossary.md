# Chronoworld — English glossary (RU → EN)

Canonical names for every translator of `locales/en/*.json`. RO things use official iRO names (kRO where iRO differs
is noted). Game-original names are fixed here once. Declined Russian forms (Пронтеры, Алана, Мастеринга…) take the
same English name. Possessive "Карта Х" → "X Card" (RO style: "Poring Card").

Style: concise game English (AFK Arena / RO tone). «» → “”. Keep {0} placeholders, emoji, ×, →, ·, %, +/−.
Title Case only for proper names, menu/screen names and item/skill/unit names; sentence case for everything else.
Address the player as "Commander" (командир). The party is "the squad".
