# Idle Hero RPG (рабочее название)

Idle-RPG в духе AFK Arena, которая будет жить в Telegram как Mini App. Дизайн-документ: [docs/GDD.md](docs/GDD.md).

**Текущая фаза: 0 — бой.** Пока это просто веб-сборка, Telegram подключается в фазе 1.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, в DevTools включите мобильный вьюпорт (например, 1080×1920 или iPhone)
npm test             # юнит-тесты: формулы, выбор цели, энергия, симулятор
npm run sim -- --n 1000                                   # зеркальный бой базовых отрядов
npm run sim -- --a guard,warrior,archer,mage,priest --b guard,assassin,archer,mage,priest --n 1000
npm run sim -- --a guard,warrior,archer,mage,priest --swaps --n 500   # проверка «замены в зеркале» (критерий ≤ 65%)
npm run build        # статическая сборка в dist/ (под Vercel/Netlify)
```

Отряд задаётся id героев через запятую по слотам: `0,1` — фронт, `2,3,4` — тыл, `-` — пустой слот.
Id героев: `guard` (Страж), `warrior` (Воин), `assassin` (Ассасин), `archer` (Лучник), `mage` (Маг), `priest` (Жрица).

## Структура

| Путь | Что там |
| --- | --- |
| `src/core/` | Чистый TypeScript без Phaser: RNG с seed, формулы, выбор цели, симуляция боя, статистика серий |
| `src/game/` | Phaser: сцены подготовки, боя (проигрывает лог) и итога; загрузка ассетов и плейсхолдеры |
| `data/heroes.json` | Статы и ульты героев |
| `data/combat.json` | Коэффициенты боя: порог шкалы, тик, лимит времени, энергия, урон, раскладка слотов |
| `data/phase0.json` | Отряды по умолчанию, скорости воспроизведения |
| `assets/manifest.json` | Все ассеты по id; `file: null` — рисуется цветной плейсхолдер |
| `scripts/sim.ts` | CLI симулятора |
| `tests/` | Vitest |

## Арт

Спрайты героев и врагов из Ragnarok Online лежат в [`assets/ro/`](assets/ro/) (владелец репозитория подтверждает права на использование). Там 12 героев, 8 рядовых врагов и 6 боссов: спрайтшиты, боевые кадры, портреты и иконки ульт. Покадровая разметка — в [`assets/ro/manifest.json`](assets/ro/manifest.json), инструкция — в [`assets/ro/README.md`](assets/ro/README.md). Задачи по графике фаз 0–2 — в [каталоге](art-research/README.md): наличие строки в каталоге **не** означает, что PNG уже есть.

В фазе 0 подключены 6 стартовых героев. В бою у каждого покадровые анимации: стойка, атака, получение урона и смерть. Фон, UI и эффекты пока остаются плейсхолдерами.

## Как подключить арт

Положите PNG в `assets/` (например, `assets/heroes/hero_guard_battle.png`) и пропишите путь в `assets/manifest.json`:
`"hero_guard_battle": { "file": "heroes/hero_guard_battle.png", ... }`. Код трогать не нужно.

## Баланс фазы 0 (после подгонки симулятором)

| Герой | HP | ATK | DEF | SPD | Ульта |
| --- | --- | --- | --- | --- | --- |
| Страж | 1550 | 60 | 60 | 95 | щит 20% HP |
| Воин | 1300 | 110 | 35 | 110 | ×1.6 |
| Ассасин | 780 | 125 | 20 | 120 | ×1.8 |
| Лучник | 900 | 120 | 20 | 135 | ×1.05, 3 выстрела |
| Маг | 900 | 150 | 15 | 95 | ×0.95 |
| Жрица | 1050 | 70 | 25 | 105 | лечение ×1.7 ATK |

Отличия от стартовых цифр GDD: у Ассасина меньше HP, ATK, SPD и множитель ульты (×2.5 → ×1.8), у Лучника выше SPD,
у Мага ульта ×0.95 и больше HP, у Жрицы лечение ульты ×1.7, у Стража меньше HP. Замеры (`npm run sim`):

- 1000 боёв — ~0.3 с;
- средняя длительность зеркального боя — ~29 с (23–50 с);
- зеркальный бой — ~50/50 (порядок ходов при равенстве шкалы решает seed);
- худшая замена героя в базовом отряде (Страж, Воин | Лучник, Маг, Жрица) — ~62% винрейта (порог 65%).
