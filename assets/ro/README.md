# Ragnarok sprites for Chronoworld

PNG files here are real decoded Ragnarok Online character/monster renders assembled into gameplay sprite sheets. The repo owner states that they have rights to upload and use the original game graphics. Sources: [ragassets](https://github.com/adsonpleal/ragassets) renderer from RO client SPR/ACT; class/monster IDs [rAthena](https://github.com/rathena/rathena). This statement records the owner's permission; it does not claim the renderer's code license licenses game art.

**26 sheets, 26 stills, 12 sprite-derived portraits, 6 skill icons.** `manifest.json` provides source URL and SHA-256 for each action, row name, chronological frame count, per-frame milliseconds, fixed cell dimensions, bottom-center anchor and effective action scale. Stills: 320×320 for ordinary sprites and 480×480 for bosses. Portraits: 256×256; skill icons: 128×128. All exported images are RGBA PNG with transparent background. Actual transparent frames at the tail of some monster death animations have been preserved rather than fabricated; repeated frames from the source are preserved too.

**Atlas playback:** rows are `idle/ready/attack/hurt/death` for heroes, `idle/walk/attack/hurt/death` for monsters; east-facing direction = 6. Columns advance chronologically, with actual count/duration per row in `manifest.json`. Crop `[column * cellWidth, row * cellHeight, cellWidth, cellHeight]`. Unused columns after `frame_count` are transparent. Character frames are not cropped or individually recentered: stable bottom-center anchor. An enormous death burst may be proportionally fitted in its row, recorded as `actions.<name>.scale`. Reflect the enemies in runtime if desired; check handed equipment before doing so.

`stills/hero_*_battle.png` uses the first **ready** frame; `stills/enemy_*.png` uses the first **idle** frame. Six portraits are magnified RO sprite busts, **not newly painted head portraits**. Hero bodies currently use their default unarmed model/head; ranged classes do not automatically show bows, wands or daggers. Equipment, polish and portrait painting need a separate pass. External URLs are provenance, never runtime dependencies.

Regenerate reproducibly from the renderer with `python tools/build_ro_spritesheets.py --phase all` (Pillow + requests). APNG source downloads are cached outside the Git repository at `/root/artifacts/chronoworld-art/ro-render-cache`; the PNG sheets, stills, portraits, icons and frame metadata are committed here. See `art-research/catalog.csv` for the complete 146-item scope; this folder covers character/monster graphics and six skill icons, **not** the requested arena, campaign backgrounds, 9-slice UI, FX, statuses, or all passive/ultimate icons.
