ПРОМТ: ФЭНТЕЗИ-ИНТЕРФЕЙС CHRONOWORLD (направление A «Тёмное золото»)

Задача
Нарисуй набор элементов интерфейса (UI kit) для мобильной idle-RPG в духе AFK Arena и Ragnarok Online. Экран вертикальный 1080×1920. Персонажи в игре — пиксельные спрайты RO, поэтому интерфейс рисованный фэнтези, но без мелкого шума: читается на телефоне.

Стиль
Тёмное фэнтези, благородное и тёплое, не мрачное.
Основа — глубокий тёмно-синий, почти ночной (#0F1320, #171D2E, #1A2135, рамки #2C3552).
Отделка — старое золото с гравировкой и тонкой филигранью (#E8B45A, светлое #F3CF86, тёмное #B8862F).
Текст на панелях светлый пергаментный (#EFE6D2).
Акценты: гемы — холодный голубой (#7FD3FF), успех — травяной зелёный (#8FD18B), опасность — киноварь (#D64545).
Материалы: полированный металл, тёмная кожа или бархат внутри панелей, лёгкое свечение по кромке у важных кнопок.
Углы — с небольшими коваными уголками, орнамент только по краям, середина элементов чистая и ровная (туда встаёт текст).
Никакого текста, букв и цифр на картинках: подписи игра рисует сама.

Технические требования (важно)
PNG с прозрачным фоном, каждый элемент — отдельный файл с именем из списка ниже.
Рисовать в указанном размере или ровно ×2.
Панели и кнопки растягиваются по 9-slice: углы не меняются, стороны и середина тянутся. Поэтому орнамент только в углах, стороны — простые повторяемые полосы, середина — однородная заливка. Для каждого такого файла укажи отступы 9-slice (слева, справа, сверху, снизу), обычно 24–40 px.
Без теней под объектом, без фона, без текста, без водяных знаков.
Единый источник света — сверху слева.

Как сдавать
Все файлы — в папку assets/ui/ репозитория, имена ровно как в списке. Для 9-slice-элементов — список отступов (можно одной строкой в сообщении). Если элемента нет, игра покажет старый вариант или заглушку, так что сдавать можно частями, начиная с пунктов 1–2.

Короткий промт для генератора картинок (на английском, по одному элементу за раз)
Game UI asset, mobile fantasy RPG in the style of AFK Arena, dark navy blue panel with ornate engraved antique gold frame, filigree only in the corners, clean flat center, polished metal and dark velvet, soft rim light from top left, isolated on transparent background, no text, no letters, front view, crisp edges, high detail, game-ready, 9-slice friendly.

Для кнопки заменить начало на: golden fantasy game button, rounded rectangle, engraved gold rim, glowing edge, no text.
Для иконки: fantasy game icon, [предмет], painted, gold rim, dark navy background circle, centered, no text.
