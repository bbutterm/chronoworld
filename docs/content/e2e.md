# Дымовой e2e-прогон (`npm run e2e`)

Быстрая проверка, что игра открывается в настоящем браузере и основной путь игрока
проходит без ошибок. Это не замена юнит-тестам (`npm test`), а «дым»: запустилось, кликается, не упало.

## Что нужно

- Playwright, установленный **глобально** (`npm root -g`/playwright). Скрипт находит его сам
  через `npm root -g` и ничего не устанавливает.
- Уже скачанный Chromium для этого Playwright.
- Свободный порт 5173 (или свой через `E2E_PORT`).

В CI не запускается: там нет браузера.

## Запуск

```bash
npm run e2e
```

Скрипт `scripts/e2e.mjs` сам поднимает vite (`--port 5173 --strictPort`), по окончании гасит его.
Код выхода 0 — всё хорошо, 1 — провал (список причин в конце вывода, плюс `fail.png` в папке скриншотов).

Переменные окружения:

| Переменная | Что делает |
|---|---|
| `E2E_PORT` | порт vite (по умолчанию 5173) |
| `E2E_SHOTS_DIR` | куда класть скриншоты (по умолчанию временная папка `idle-rpg-e2e-<время>` в `os.tmpdir()`) |
| `E2E_HEADED=1` | показать окно браузера |

## Сценарий

1. Открыть игру, **очистить localStorage**, перезагрузить. Картинки при этой загрузке
   придерживаются на 0,7 с — успевает сняться экран загрузки (`01-loading.png`).
2. Главная → «Кампания» → этап 1 → «В бой».
3. В бою: кнопка скорости `1x` → `2x`, проверка, что выбор записан в localStorage
   (`chronoworld.battleSpeed`); «Пропустить» → экран итогов.
4. Итог → «К кампании» → «Главная» → «Герои» → карточка первого героя → «‹ Назад».
5. Тестовый бой (отряды из `data/phase0.json`, seed 7): ждём баннер ульты, ставим бой на паузу
   и снимаем его; «Пропустить» → итог.

Проверки на всём пути:

- нет `console.error` и `pageerror` (кроме 404 на favicon);
- `<canvas>` есть;
- после каждого перехода активна ожидаемая сцена.

Если ульта за 30 с не случилась, скриншот баннера пропускается — это не ошибка.

## Как кликает

Канвас масштабирован под окно (540×960 при игре 1080×1920), поэтому клики — в координатах игры
с пересчётом по размеру канваса. Кнопки ищутся по **тексту подписи** в активной сцене
(`window.__game`, есть только в dev-сборке): находим объект `Text` с точным совпадением,
берём центр его границ и кликаем туда. Переименовали кнопку — поправьте подпись в скрипте.
Карточка героя кликается по фиксированной точке (540, 430).

## Когда запускать

Перед коммитом, меняющим сцены, навигацию, загрузку ассетов или `main.ts`.

## Дополнительные шаги (пакет R)

- На чистой игре проверяется подсказка новичку на Главной.
- На итогах этапа 1 включается «Авто: следующий этап» → этап 2 запускается сам, флаг запоминается.
- На итогах этапа 2 — отсчёт авто-перехода и его отмена касанием («Авто отменено»).
