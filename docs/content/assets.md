# Ассеты в сборке

Арт лежит в `assets/`. Игра запрашивает файлы по путям **внутри** `assets/` (например `ui/ui_hp_player.png`,
`sprites/heroes/guard.png`) относительно `index.html` (`base: './'`).

## Dev и сборка

- `npm run dev` — Vite отдаёт всю папку `assets/` с корня (`publicDir: 'assets'`), как раньше.
- `npm run build` — `publicDir` выключен; плагин `idle-rpg:used-assets` в `vite.config.ts` кладёт в `dist/`
  **только нужные** файлы по тем же относительным путям, поэтому URL не меняются.

Список нужных файлов считает `scripts/lib/used-assets.ts`:

| Источник | Что попадает в dist |
|---|---|
| `assets/manifest.json` | каждый `file` и `atlasXml` (BootScene грузит манифест целиком) |
| реестр спрайтов (`assets/sprites/sprites.json` + `assets/sprites.legacy.json`, v2 перекрывает по id) | только спрайты, на которые ссылается `visual.sprite` в `data/units/*.json` и `data/jobs/*.json`: их лист `file` и `portrait` |

Сами `manifest.json`, `sprites.json` и `sprites.legacy.json` импортируются в JS-бандл при сборке и отдельно не копируются.
README, лицензии, `assets/ro/manifest.json`, `ro/stills/` и старые листы монстров, на которые не ссылается контент, в `dist/` не попадают.

Если нужный файл отсутствует на диске, сборка выводит предупреждение (в игре будет плейсхолдер), но не падает.

## Как добавить арт

1. Положить файл в `assets/` и сослаться на него: запись в `assets/manifest.json` **или** спрайт в реестре +
   `visual.sprite` у юнита/профессии.
2. `npm run assets:report` — убедиться, что файл в списке нужных.

Файл, на который никто не ссылается, в сборку не попадёт — это намеренно.

Без записи в манифесте игра сама находит по имени (и берёт в сборку):

- **фоны глав** `assets/backgrounds/bg_battle_ch<N>.(jpg|png|webp)` (поле боя) и `bg_map_ch<N>.*` (карта кампании),
  N — номер главы (1 луг, 2 топь, 3 склеп; ярусы башни — так же по порядку). Файла нет — фон рисуется кодом
  (`src/game/backdrops.ts`); есть — грузится при первом показе главы и подменяет нарисованный. Держим не больше
  одного такого фона на вид (бой/карта), поэтому файл 1080×1920 стоит ≈ 8 МБ видеопамяти только пока нужен.
  Поле боя: отряды стоят на y ≈ 900–1840 из 1920 — эту полосу держите спокойной, без крупных деталей;
- **бюсты героев** `assets/ro/portraits/hero_<класс>_portrait.png` — портрет в рамке в диалогах и на смене
  профессии (`src/game/portraitFrame.ts`); класс = id спрайта (кроме `priestess` → `priest`). Нет бюста —
  верх портрета спрайта.

## `npm run assets:report`

Печатает:

- размер всех / нужных / лишних файлов в `assets/`;
- файлы, на которые есть ссылки, но которых нет на диске, и спрайты из контента без записи в реестре;
- 10 самых больших файлов (с пометкой нужен/лишний);
- PNG больше 2048 px по стороне — часть мобильных GPU такие текстуры не держит, нужные листы такого размера надо резать.
