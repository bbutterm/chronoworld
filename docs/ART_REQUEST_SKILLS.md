# Заказ арта: эффекты и иконки навыков героев

Для художника (или агента-художника). Все эффекты ниже УЖЕ нарисованы кодом (процедурно, `src/game/skillSigs.ts`) —
арт заменяет их как улучшение, игра не ждёт. Иконки: у всех навыков героев, кроме одного, уже есть настоящие иконки RO.
Полная таблица «как сейчас» — `docs/content/skills-vfx.md`.

## Коротко для художника (скопировать в мессенджер)

```
Нужны эффекты навыков для боя Chronoworld (мир и стиль Ragnarok Online). Сейчас все эффекты нарисованы кодом, твой арт их заменит.
Формат: PNG-лента кадров с прозрачным фоном, кадры одного размера в ряд (можно в несколько рядов), 12 кадров в секунду, без размытия, пиксель-арт или мягкое свечение как в RO.
Файл кладёшь в assets/effects/fx_<id навыка>.png и пишешь размер кадра, число кадров и точку привязки (куда ставить на цели: обычно центр низа для площади, центр для попадания).
Размеры: попадание 256x256, аура на герое 256x320, площадь на цель 512x256 или на всё поле 768x384, снаряд 128x64.
Сначала P1 (навыки базовых форм 12 героев, видны в главах 1 и 2), потом P2 (фиолетовые ветки), потом P3 (пассивки и монстры).
Ориентир — оригинальный эффект RO из списка (например Bowling Bash, Storm Gust, Grand Cross, Meteor Storm). Цвет и общий вид — как в колонке «сейчас».
Иконка нужна одна: Удар сковородой (job_merchant_frying_pan) — пиксель-арт 24x24 в стиле иконок навыков RO, прозрачный фон, файл assets/ui/icons/skill_mc_fryingpan.png.
Полный список с id — docs/ART_REQUEST_SKILLS.md.
```

## Формат (как у существующих эффектов)

- Лента кадров PNG (RGBA) → `assets/effects/fx_<id навыка>.png`; запись в `assets/effects/effects.json → effects`:
  `id`, `file`, `cell` [ширина, высота кадра], `columns`, `frames`, `ms` (83.33 = 12 к/с), `delayMs`, `anchor` [x, y в кадре],
  `attach` (`target` / `caster`), `blend`. Пример и правила — `assets/effects/README.md`, `docs/ART_EXTRACT_RO.md` §1.
- Привязка к навыку: `effects.json → skills`: `{"<id навыка>": {"hit": "fx_<id>", "buff": "fx_<id>"}}` — hit показывается на цели
  урона, buff — на союзнике со статусом. Площадь на всё поле и снаряд подключает агент (строка в `skillSigs.ts`, рецепт
  рисует лист вместо процедурных частей).
- Анимированные листы грузятся лениво при первом бое; один лист ≤ 2048 px по стороне; вес — `npm run assets:report`.
- Иконки: 24×24 пиксель-арт RO (как `assets/ui/icons/skill_<ro>.png`), игра кладёт в свою рамку ×3.
