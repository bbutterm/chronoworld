# Отчёт: ночь 26→27.09.2026

Ветка: `claude/idle-hero-rpg-gdd-rolicg`. Все слияния — с зелёным `npm run check` (контент, типы, тесты; ~290 тестов) и `npm run build`. CI: `.github/workflows/check.yml`.

## Что сделано

**Ядро (src/core, всё на данных, детерминировано, покрыто тестами)**
- Прогрессия: 19 профессий (Новичок → 6 первых → 12 вторых, как в RO), 88 навыков, открытие навыков на джобах 1/10/20/30/40, смена профессии на джобе 10 и 50.
- Кампания: 3 главы × 10 этапов, боссы глав, рост силы врагов, награды, офлайн-сундук (лимит 12 ч).
- Сохранение: версии и миграции (v0→v3), битое сохранение не роняет игру.
- По образцу AFK Arena (K1–K10): быстрые награды, мощь, башня испытаний (100 этажей, босс каждые 5), ежедневные задания с активностью, экипировка (4 слота × 3 редкости, выпадение), пропуск/повтор боя, пресеты и авторасстановка, доска поручений, достижения.
- Бой: выход из «застревания», крайние случаи; спрайты v2 с оружием (масштаб ×2.5).

**Экраны (src/game)** — Главная (сундук, быстрые награды, плитки Задания/Башня/Поручения/Достижения), Кампания-тропа, подготовка этапа с мощью и отрядом, бой этапа/башни, итоги с наградами и трофеями, Герои, карточка героя со снаряжением, Инвентарь, смена профессии, Отряд (авто, пресеты), Башня, Задания, Поручения, Достижения. Скриншоты: `docs/REPORTS/screens/` (f-*, h-*, m-*).

**Инструменты** — `npm run content:check` (всё: схемы, ссылки, ассеты, конфиги функций), `npm run balance` (модельный игрок 14 дней, CSV, стены, экономика), `npm run sim`.

## Как проверить руками
1. `npm install && npm run dev`, открыть в мобильном вьюпорте.
2. Главная → «В кампанию» → этап 1 → «В бой» → итоги → дальше по этапам.
3. «Герои» → герой → на джобе 10 «Сменить профессию».
4. Башня откроется после этапа 5; задания и поручения — плитки на Главной.
5. `npm run balance -- --days 14` — сводка прогресса.
