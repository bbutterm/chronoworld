# Подтверждение исправления прокрутки инвентаря — 2026-10-05

Один и тот же нативный путь в 360×640 Canvas воспроизвёл проблему до исправления и прошёл после интеграции общего modalInput guard. Под открытым подтверждением продажи wheel dy=300 раньше сдвигал список 0→300; в неизменяемой AFTER-сборке offset остался 0→0, content.y 482→482. Вопрос остался живым и неподвижным. Save и счётчик записей 11 сохранились точно.

Настоящая «Отмена» закрыла вопрос без записи. Затем обычный wheel сдвинул список 0→240; locked=false. Поэтому передача от itemSheet с прежним locked=true не оставляет инвентарь заблокированным. Все 50 проверок прошли; ошибок консоли нет. Собственный браузер закрыт.
