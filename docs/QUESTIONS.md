# Вопросы к владельцу

Формат: вопрос → что выбрано по умолчанию → где поменять.

## Сохранение (пакет C)

1. **Битое сохранение не стирается сразу**: игра начинается заново, старые данные перезапишутся при первом сохранении. → Сейчас без резервной копии. Нужно ли сохранять копию в `chronoworld.save.v1.broken`? → `src/core/save/save.ts` (`loadOrNew`).
2. **Проверять ли при загрузке, что профессии и этапы из сохранения есть в контенте?** → Сейчас не проверяется, чтобы переименование в контенте не обнуляло прогресс. Если нужно — делать мягкий ремонт, а не сброс.
3. **Сохранение без поля `version`** считается ошибкой, а не версией 0. → Если реальных старых сохранений нет, так и оставить.
4. **Две вкладки** перезаписывают сохранения друг друга. → Защиты нет; для Telegram Mini App, скорее всего, не нужна.

## Кампания и офлайн (пакет B)

1. **Боссы глав.** В реестре спрайтов v2 только `boss1`, `boss2`. → Глава 1 — `mob_boss1`, `mob_boss2` — заготовка на главу 2. Для главы 3 нужен спрайт (пока будет плейсхолдер).
2. **Офлайн-опыт получают все герои**, а не только отряд. → Как в контракте. Поменять — `src/core/campaign/offline.ts` (`claimOffline`).
3. **Опыт за повтор этапа** урезается тем же `replayRewardMultiplier` (0.5), что и золото. → Нужен ли отдельный множитель? → `data/progression.json`.
4. **Сундук считает по ставке последнего пройденного этапа на момент сбора** (прошли новый этап — накопленное пересчитается по новой ставке). → Проще; в AFK Arena так же фактически. Фиксировать накопленное при прохождении — по запросу.
5. **Проходимость главы 1 пятью новичками** (без баланса): этапы 1–4, 6 — на джобе 1; 5 — с джоба 5; 8 — на 10; 7, 9, 10 — только с первыми профессиями. Цифры — заглушки, подгоним в балансе.
