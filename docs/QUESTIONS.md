# Вопросы к владельцу

Формат: вопрос → что выбрано по умолчанию → где поменять.

## Сохранение (пакет C)

1. **Битое сохранение не стирается сразу**: игра начинается заново, старые данные перезапишутся при первом сохранении. → Сейчас без резервной копии. Нужно ли сохранять копию в `chronoworld.save.v1.broken`? → `src/core/save/save.ts` (`loadOrNew`).
2. **Проверять ли при загрузке, что профессии и этапы из сохранения есть в контенте?** → Сейчас не проверяется, чтобы переименование в контенте не обнуляло прогресс. Если нужно — делать мягкий ремонт, а не сброс.
3. **Сохранение без поля `version`** считается ошибкой, а не версией 0. → Если реальных старых сохранений нет, так и оставить.
4. **Две вкладки** перезаписывают сохранения друг друга. → Защиты нет; для Telegram Mini App, скорее всего, не нужна.
