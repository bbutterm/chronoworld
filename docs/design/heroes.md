# Карточки героев, редкость, слияние и призыв (в стиле AFK)

Статус: одобрено владельцем (27.09, «Звучит хорошо» — все 5 ответов по умолчанию) с одним изменением (27.09 ~20:40):
**новичков и материалов для смены профессии нет** — сюжетные герои сразу зелёные карточки своего класса и растут
**осколками героя** (как в AFK), вторая профессия сюжетного героя = переход его карточки синий → фиолетовый.
Ядро и данные — пакеты H1–H3 (реализованы: `src/core/heroes/*`, `data/heroes`, `data/cards.json`, `data/summon.json`);
экраны — H4 «Герои», H5 «Таверна». API ядра для экранов — `docs/AGENTS.md`, раздел «Карточки героев».

Исходное решение владельца 27.09 (~20:10): «вернуться к концепции AFK» — герой = карточка
с именем, полом, классом, ролью, своими навыками и историей; карточки выпадают из призыва за гемы, копии сливаются
в более высокую редкость; вторые профессии сразу фиолетовые; отдельный интерфейс «Герои».
Документ заменяет раздел 8 GDD («джобы») в части «кто такой герой» и выносит фазу 3 GDD («Коллекция») вперёд.
Все числа — стартовые, до прогона `npm run playthrough` / `npm run balance`.

Термины: **шаблон карточки** (`data/heroes/<id>.json`) — кто это; **экземпляр** (в сохранении) — конкретная карточка
игрока с редкостью и уровнем; **линия** — корень ветки RO (мечник, лучник, маг, вор, аколит, торговец);
**класс** — профессия из `data/jobs` (мечник, рыцарь…); **корм** — карточки, которые тратятся на слияние.

## 1. Карточка героя

| Поле | Смысл |
| --- | --- |
| `id`, `name`, `gender` (`m`/`f`) | уникальный человек: «Алан» и «Ирис» — разные карточки одного класса |
| `job` | класс (id из `data/jobs`): даёт обычную атаку (`basic`), кривую статов линии, спрайт по умолчанию |
| `line` | линия (id первой профессии: `swordman`…); для первых профессий = `job`. Показывается как гильдия/город (см. ниже) |
| `role` | `tank` / `damage` / `healer` / `support` — своя у карточки, может отличаться от роли класса |
| `source` | `story` (выдаёт сюжет, в призыве нет) или `summon` |
| `baseRarity`, `maxRarity` | с какой редкости выпадает / до какой растёт (раздел 2) |
| `statMods` | множители к статам класса `{hp, atk, def, spd}` — танк и ДД одного класса различаются здесь |
| `skills` | `[{level, skill}]` — 4 навыка из `data/skills` (раздел 1.3), уровни открытия по возрастанию |
| `forms` | только у сюжетных: вторая профессия `[{rarity: "purple", job, role?, statMods, skills}]` — активна с этой редкости |
| `visual` | необязательные `sprite`, `portrait`, `card` — переопределения (правила поиска ниже) |
| `bio` | 1–2 строки, кто это (≤ 160 симв.) |
| `hook` | 1–2 строки личной истории — крючок для будущих сцен (≤ 200 симв.) |

**Гильдия (фракция) по линии** — только подпись и фильтр, без бонусов (треугольник фракций GDD — позже, если вообще):
мечник, аколит — Пронтера; маг — Гефен; лучник — Пайон; вор — Морок; торговец — Альберта.

**Статы экземпляра** (одна формула для всех карточек):

```
stats(L) = (lineJob.baseStats + lineJob.growth × (L − 1)) × template.statMods × rarity.statMult
```

`lineJob` — первая профессия линии (для Рыцаря — Мечник). Базы tier 2 из `data/jobs` (рассчитанные на ур. ~30)
карточками не используются, иначе фиолетовая карточка 1-го уровня была бы ×2.5 зелёной. Сила второй профессии —
в `statMods` (сумма множителей ≈ ×1.2–1.3 к первой профессии) и в редкости. Юнит боя строит `buildUnit` как сейчас
(+ экипировка), навыки — открытые по уровню из `skills` шаблона/формы.

**Спрайт и портрет** (поиск, первое найденное): `visual.sprite` → `<лист класса>_<gender>` (`swordman_f`) →
лист класса (`swordman`) → плейсхолдер по роли. Откат пола — ⚠ в content:check (не ошибка), список листов для
художника — issue #19. Портрет: `visual.portrait` → бюст RO (`portraitFrame.ts`) → портрет спрайта. Большой арт
карточки: `assets/heroes/card_<id>.png` (новый арт, 600×900) → увеличенный кадр idle спрайта на фоне цвета редкости.

## 2. Редкость и слияние

| Редкость | id | Цвет рамки | Макс. уровень | Статы × | Сила навыков × |
| --- | --- | --- | --- | --- | --- |
| Зелёный (обычный) | `green` | #4CAF50 | 20 | 1.00 | 1.00 |
| Синий (редкий) | `blue` | #3F8CFF | 40 | 1.10 | 1.00 |
| Фиолетовый (эпический) | `purple` | #A05CFF | 60 | 1.25 | 1.00 |
| Золотой (легендарный) | `gold` | #F5B82E | 80 | 1.45 | 1.15 |
| Красный (мифический) | `red` | #E0443A | 100 | 1.70 | 1.30 |

- **Навыки** открываются уровнем (из шаблона: обычно 1/10/30/50) → зелёный (до 20) владеет 2 навыками, синий — 3,
  фиолетовый — всеми 4. «Сила навыков» на золотом и красном — множитель `k` урона/лечения/щита навыков карточки
  (`Unit.skillPower`, по умолчанию 1; в `formulas.ts` одно умножение). На экране — «Навыки ур. 2 / ур. 3».
- **Кто откуда:** первые профессии из призыва — зелёные или синие, максимум **золотой**; вторые профессии — сразу
  **фиолетовые**, максимум **красный**; сюжетные — **зелёные с первого дня**, максимум красный, растут осколками (раздел 3).
- **Звёзды** (после красного, 1–5★ за фиолетовые копии той же карточки) — позже, отдельным пакетом.

### Правила слияния («Вознесение»)

Цель — карточка, которую повышаем; корм тратится. «Та же» — тот же шаблон; «линии» — любой шаблон той же линии.
Призывные карточки растут **копиями** (корм), сюжетные — **осколками героя** (корм им не нужен, и сами они не корм).

| Переход | Первые профессии (призыв) | Вторые профессии (призыв) | Сюжетные (осколки) |
| --- | --- | --- | --- |
| зелёный → синий | +2 той же (зелёных) | — | 20 осколков |
| синий → фиолетовый | +1 той же (синяя) +2 линии (синих) | — | 40 осколков, ур. 40 — **вторая профессия** (Алан → Рыцарь) |
| фиолетовый → золотой | +1 той же (фиолетовая) +2 линии (фиолетовых) | +2 той же (фиолетовых) | 60 осколков |
| золотой → красный | нельзя (максимум) | +1 той же (фиолетовая) +2 линии (фиолетовых) | 80 осколков |

Плюс золото: 500 / 5 000 / 20 000 / 60 000 за переходы по порядку (заглушки). Правила — данные (`data/cards.json → merge`,
`track`: `first` — первые профессии призыва, `second` — вторые, `story` — сюжетные).

- Корм: не в отряде, пресетах и на поручениях, не «закреплён» (замок на карточке), не сюжетный.
- Уровень цели сохраняется; опыт и золото, вложенные в корм, возвращаются в пул и в золото (как в AFK), экипировка корма — в инвентарь.
- Дубль из Таверны всегда полезен: копия — корм для своей карточки или карточек линии (критерий фазы 3 GDD).
- В отряде — не больше одного экземпляра шаблона (ядро: `duplicate_card`; дубли в редакторе серые).

| Источник | Сколько | Чьи |
| --- | --- | --- |
| Первое прохождение этапа кампании | 4 (босс главы — 8) | герой этапа — «отстающий» сюжетный герой (`stageShardHero` = `shardTarget`, видно до боя): рекруты догоняют тройку |
| Повтор пройденного этапа (победа) | шанс 10% — 1 | тот же «отстающий» (от seed боя) |
| Поручения редкие / эпические | 2 / 5 (`rewards.shards`) | «отстающий» сюжетный герой (`shardTarget`: ниже редкость, меньше осколков) |
| Достижения | 5–10 у части (`rewards.shards`) | отстающий |
| Таверна | шанс 10% за призыв — 1 | отстающий |

Модель игрока (`npm run playthrough`, только кампания): тройка становится синей в главе 2, Грета и Дорн — к середине главы 3,
раньше, чем упрутся в предел зелёного (ур. 20); поручения и достижения ускоряют. Следующий переход (фиолетовый, ур. 40,
40 осколков) — уже за пределами глав 1–3.
Осколки героя, которого ещё нет в отряде (Грета до `ch1_s10`), не выпадают.

### Уровень

Опыт героев — **общий пул** (`resources.heroExp`, как в GDD фазы 1 и в AFK): награды этапов, сундука, башни, поручений
идут в пул, кнопка «Улучшить» на карточке тратит опыт + золото. Стоимость уровня L → L+1: опыт `floor(100 × L^1.5)`
(прежняя кривая `progression.exp`, теперь `data/cards.json → level`), золото `floor(15 × L²)` (баланс 27.09, `docs/content/balance.md`). Упор в предел
редкости — кнопка «Вознести». Награды «опыт» в данных (`rewards.jobExp` этапов, сундука, башни, поручений, заданий) — это опыт
**в пул**; все числа умножены на 3 (размер стартового отряда): темп главы 1 прежний (к боссу ур. 4–5), глава 3 по часам
сундука — как раньше (`npm run playthrough -- 2 3 --idle`: ~100 ч на главы 1–3).

## 3. Стартовые герои и сюжет

Сюжетные герои — **фиксированные карточки** (в призыве их нет) с формой второй профессии; остальные — отдельные карточки.
Новичков и смены профессии нет: герой с первого дня — зелёная карточка своего класса, ур. 1.

| Карточка | Когда | Класс (зелёный, синий) | Вторая форма (фиолетовый и выше: ур. 40 + 40 осколков) |
| --- | --- | --- | --- |
| Алан (м) | старт игры | Мечник-танк | Рыцарь-танк: `job_swordman_provoke`, `swordman_endure`, `job_knight_auto_counter`, `job_knight_bowling_bash` — его мечта |
| Бран (м) | старт | Лучник | Охотник: `job_archer_double_strafe`, `job_hunter_beast_bane`, `job_hunter_ankle_snare`, `job_hunter_blitz_beat` |
| Вика (ж) | старт | Аколит-лекарь | Жрица: `job_acolyte_heal`, `job_priest_impositio_manus`, `job_priest_magnus_exorcismus`, `job_priest_sanctuary` |
| Грета (ж) | после `ch1_s10` | Торговка («сковородка») | Кузнец: `job_merchant_frying_pan`, `job_blacksmith_tempering`, `job_blacksmith_hammer_fall`, `job_blacksmith_power_thrust` |
| Дорн (м) | после `ch2_s10` | Вор | Разбойник: `job_thief_steal`, `job_rogue_raid`, `job_thief_improve_dodge`, `job_rogue_strip_weapon` |

- Рекрут приходит зелёной карточкой ур. 1 и встаёт в свободный слот отряда; общий пул опыта быстро поднимает его до отряда.
- **Вторая профессия сюжетного героя** = вознесение синий → фиолетовый за осколки (ур. 40); класс фиксирован, выбора ветки
  нет. Остальные вторые профессии — фиолетовые карточки призыва.
- Экран смены профессии (`JobChange`) и материалы убраны из игры; `data/jobs/novice.json` остаётся только как корень дерева
  профессий (проверки `validateJobs`).
- Почему так: владелец хочет «вторые профессии сразу фиолетовые» (карточки призыва) и «разные истории» — у сюжетных
  героев история и есть их рост (Алан становится рыцарем в сюжете), а призывные — отдельные люди. Осколки (а не корм линии)
  делают рост сюжетных понятным и не отнимают дубли у призывных карточек.
- Сюжетные реплики: спикеры `hero1..hero5` — сюжетные герои по порядку `progression.heroes.start` + `recruits`
  (Алан, Бран, Вика, Грета, Дорн): имя и портрет — из карточки игрока.

## 4. Призыв («Таверна»)

Открывается после `ch1_s5` (вместе с Башней; Гаррет: «В таверне Пронтеры ищут работу наёмники»). Плитка на Главной.

| Параметр | Значение |
| --- | --- |
| Цена | 1 призыв — 30 гемов; ×10 — 270 гемов; или «Свиток призыва» (1 шт. = 1 призыв) |
| Шансы | зелёный 64%, синий 32%, фиолетовый 4% |
| Внутри редкости | равновероятно среди шаблонов `source: summon` нужной редкости (зелёный/синий — 7 первых профессий, фиолетовый — 13) |
| Гарант | 30-й призыв без фиолетового — фиолетовый (счётчик `sincePurple` общий для платных, свитков и бесплатных) |
| Первый ×10 | содержит фиолетовый (последняя карта, если не выпал раньше); только один раз |
| Бесплатный | 1 призыв в день (по `day` от UI, защита от перевода часов — как у `daily.usedDays`) |
| Дубликаты | обычные экземпляры — корм для слияния; первая копия шаблона — значок «Новый!» |
| Осколки | каждый призыв с шансом 10% приносит ещё 1 осколок «отстающего» сюжетного героя |
| Приветствие | при открытии Таверны (первая победа на `ch1_s5`): 150 гемов + 10 свитков — сразу первый ×10 (сюжетная награда Гаррета; было 1 свиток, баланс 27.09) |

**Доход гемов в первую сессию** (этапы 1–10, башня до 5): достижения «Путешественник» 20 + «Восхождение» 20, босс башни
эт. 5 — 20, ежедневная активность 40 и 100 очков — 20 + 50 (≈ 110 очков набирается в первую сессию) ≈ **130** + приветствие
**150** = 280 ≥ 270 → первый ×10 в первой сессии. Дальше ≈ 70 гемов/день с заданий + бесплатный призыв ≈ 3–4 призыва
в день. Свитки добавить в награды: «Боевое крещение» (1), каждый 10-й этаж башни (1), босс главы (2). Быстрые награды
за гемы (50/80/100) остаются — конкурирующая трата, проверить в `npm run balance` (новая строка «призывы/день»).

**Ядро детерминировано:** `summon(save, ctx, {count, pay: 'gems'|'scroll'|'free', day})` → `{save, results[]}`;
seed = `hash(save.createdAt, save.summon.seq)`, `Rng` из `src/core/rng.ts`, `seq` растёт на 1 за вызов. Один seed —
одна выдача (тест), повторное открытие вкладки не перебрасывает результат (он уже в сохранении).
Шансы, гарант и первый ×10 проверены статистически на seed'ах (`tests/heroes-summon.test.ts`).

## 5. Интерфейс

**«Герои» (нижняя навигация, заменяет нынешний список)**
- Сетка карточек 3 в ряд: портрет в рамке цвета редкости, уровень, значок класса и роли, «Новый!», замок.
- Фильтры сверху: линия (6 значков), роль (4), редкость (5); сортировка: сила / редкость / уровень. Счётчик «28/40».
- Карточки, которые можно вознести, — зелёная стрелка в углу.

**Карточка героя** (`HeroScene`)
- Верх: большой арт (раздел 1), рамка и фон цвета редкости, имя, класс, роль, гильдия, пол-значок.
- Статы (русские подписи), сила; кнопка «Улучшить» (опыт + золото, долгое нажатие — ×10); предел — «Вознести».
- Навыки: 4 значка, закрытые — замок и «откроется на ур. 30 / нужен фиолетовый»; нажатие — описание.
- Вкладка «История»: `bio` + `hook`, позже — сцены. Экипировка — как сейчас.
- Стрелки ← → по отфильтрованному списку.

**Вознесение** (модальный экран): цель слева → результат справа (новый цвет, предел, статы «было → стало»); ниже слоты
корма («та же» и «линии») — нажатие открывает список подходящих, кнопка «Авто» подбирает самые слабые; неподходящие
не показываются. Подтверждение, если в корме синий и выше. Анимация: корм втягивается, вспышка цвета новой редкости.

**Таверна** (`SummonScene`): фон таверны, счётчик гемов/свитков, «до гаранта: N», кнопки «Бесплатно», «×1 — 30»,
«×10 — 270». Показ как в AFK: карты рубашкой вверх летят на стол, тап — переворот (фиолетовый — вспышка и дрожь),
«Открыть все», «Пропустить»; итог — сетка с «Новый!» и кнопками «Ещё ×10» / «К героям». Уменьшение анимаций —
сразу итог.

**Отряд** (редактор AFK-расстановки, агент «расстановка»): ростер снизу — карточки с рамкой редкости, фильтр линии/роли,
дубли шаблона серые. Поручения и авторасстановка берут роль карточки.

## 6. Данные, сохранение, проверки

**Файлы**
- `data/heroes/<id>.json` — шаблоны (`HeroTemplateSchema`, `src/core/heroes/schema.ts`), 12 + 13 сейчас.
- `data/cards.json` — редкости (таблица раздела 2), правила слияния, стоимость уровня.
- `data/summon.json` — цены, шансы, гарант, первый ×10, бесплатный, приветствие, `unlockAfterStage`.
- `data/progression.json → heroes`: `start: ["alan","bran","vika"]`, `recruits: [{afterStage, template}]` (вместо имён).
  `jobChange`, `exp.byTier`, пулы имён удалены.

Пример шаблона:

```json
{ "id": "iris", "name": "Ирис", "gender": "f", "job": "swordman", "line": "swordman", "role": "damage",
  "source": "summon", "baseRarity": "green", "maxRarity": "gold",
  "statMods": { "hp": 0.9, "atk": 1.25, "def": 0.75, "spd": 1.05 },
  "skills": [ { "level": 1, "skill": "swordman_bash" }, { "level": 10, "skill": "job_knight_two_hand_mastery" },
              { "level": 30, "skill": "job_swordman_magnum_break" }, { "level": 50, "skill": "job_swordman_auto_berserk" } ],
  "bio": "Мечница с двуручником. Щит считает лишним весом.",
  "hook": "Изгнана из ордена Пронтеры: бросила щит, чтобы вынести раненых." }
```

Сюжетный: `"source": "story", "baseRarity": "green", "maxRarity": "red", "job": "swordman", …, "forms": [{ "rarity": "purple",
"job": "knight", "role": "tank", "statMods": {…}, "skills": [4 навыка] }]` — у формы свои `job/role/statMods/skills`;
активная форма — последняя с `rarity` ≤ редкости экземпляра.

**Сохранение v4** (`SAVE_VERSION = 4`, миграция в `MIGRATIONS[3]`, `src/core/heroes/migrate.ts`):
- `heroes[]`: `{ id, templateId, rarity, level, locked?, isNew? }`; `name/gender/job/jobLevel/jobExp/jobHistory/bankedExp` уходят
  (имя, пол, класс — из шаблона).
- `resources.heroExp` (пул), `currency.scrolls`, `shards: {шаблон: число}`,
  `summon: { seq, total, sincePurple, firstTenDone, freeDay?, welcomeGiven, discovered[] }`, `notices?` (одноразовые
  сообщения игроку: `sanitizeSave` отдаёт их в `warnings` и убирает).
- Миграция (не зависит от текущего `data/`): герой → сюжетная карточка **по имени** (Алан → alan; Бран, Бэлла → bran;
  Вика, Вик → vika; Грета, Грег → greta; Дорн → dorn), иначе — первая свободная сюжетная по порядку; уровень — **тот же**
  (Новичок и первая профессия — `jobLevel`, вторая — `40 + jobLevel`, не выше 60), редкость — самая низкая, чей предел
  вмещает уровень (≤ 20 зелёный, ≤ 40 синий; вторая профессия — фиолетовый); `jobExp` и `bankedExp` → пул `heroExp`.
  Лишние герои (шестой и дальше) → зелёная призывная карточка своей линии. Компенсация — 1 свиток призыва и сообщение
  «Герои стали карточками…» (с перечнем, если класс сменился: «Алан теперь Мечник»). Если `ch1_s5` уже пройден — сразу
  подарок Таверны. id героев не меняются → отряд, пресеты, поручения, `equippedBy` остаются.
- `sanitizeSave`: неизвестный `templateId` → экземпляр убирается (с предупреждением), ссылки на него чистятся; второй
  экземпляр шаблона в отряде убирается; вещи, которые герой больше не может носить, снимаются.

**content:check** (ошибки ✗ / предупреждения ⚠)
- ✗ id уникален и `^[a-z][a-z0-9_]*$`; `job` существует; `line` = корень ветки `job`; `gender ∈ m|f`; роль из enum.
- ✗ `baseRarity`: tier 1 + `summon` → green/blue, tier 2 → purple, `story` → green (tier 1);
  `maxRarity ≥ baseRarity`, у первых профессий призыва ≤ gold; форма сюжетного — вторая профессия своей линии.
- ✗ навыки существуют; уровни открытия уникальны, возрастают, ≤ предела `maxRarity`; 3–4 навыка на форму.
- ⚠ навык не своей линии (кроме навыка ветки-предка и исключений `hero.skillExceptions`); ⚠ у двух карточек класса
  общих навыков > 2 или одинаковый фирменный; ⚠ спрайт пола не найден (откат).
- ✗ `bio` ≤ 160, `hook` ≤ 200, имена карточек уникальны; ✗ `progression.heroes.start/recruits` ссылаются на `story`-шаблоны.
- ✗ `summon.json`: шансы в сумме 1, для каждой выпадающей редкости пул не пуст, гарант ≥ 10; `cards.json`: все редкости
  по порядку, правила слияния ссылаются на существующие редкости.
- Дымовой бой: каждый шаблон на пределе каждой своей редкости (как сейчас для профессий).

**Тесты** (`tests/heroes-*.test.ts`)
1. Статы по формуле, пределы уровней, открытие навыков по уровню, `skillPower` на золотом/красном.
2. Призыв: один seed — одна выдача; шансы на 100 000 призывов в пределах ±0.5 п. п.; гарант на 30-м; первый ×10 с
   фиолетовым; бесплатный раз в день и не повторяется переводом часов; нехватка гемов/свитков — ошибка без изменений.
3. Слияние: верный/неверный корм, корм в отряде/пресете/поручении/закреплённый — отказ, возврат опыта и золота,
   экипировка корма в инвентаре, предел редкости; осколки: списание, нехватка, требование уровня, сюжетная форма
   меняется на фиолетовом; источники осколков (этапы, повторы, поручения, достижения, Таверна).
4. Уровень из пула: списание, упор в предел, ×10.
5. Миграция v3 → v4 на фикстурах (новичок, первая, вторая, «чужой» класс, рекруты, старые имена Бэлла/Вик/Грег, пресеты, предметы).

7. Контент: валидатор на плохих шаблонах; `chapter1-playthrough` зелёный без изменения ожиданий (сюжетная тройка).
8. e2e: Герои → карточка → «Улучшить» (подписи кнопок в `scripts/e2e.mjs`); Таверна → ×10 — в H5.
