# Бой с решениями (задача 1 плана 01.10)

Владелец: бои слишком лёгкие и не захватывают; «важно не переусложнить». Цель — дать игроку 2–3 понятных решения
(кого взять, когда нажать ульту) без новых экранов и без ломки авто-боя. Всё детерминировано: бой = seed + вводы игрока.

## 1. Ульта вручную

Что. У каждого героя одна «ульта» — активный навык с самой долгой перезарядкой (не меньше `combat.json → manual.minCooldown`,
10 с; равенство — открытый позже). Это ровно тот «большой» навык, который и так виден баннером: Гроза, Метеоритный дождь,
Асура, Assumptio… Юниты с `skills.ult` (тестовый бой, монстры) — их ульта на 100 энергии.

- Авто (как было): ульта срабатывает сама по перезарядке. Баланс авто не меняется — idle, офлайн, `actSkipStage`,
  зачистка, скрипты баланса считают бой без ввода (режим по умолчанию в ядре — авто).
- Вручную: ульта героя стороны A не срабатывает сама. Когда готова — событие `ready`, портрет на панели светится и
  пульсирует. Касание портрета → ввод `{ t, uid }` (t — следующий тик симуляции после текущего времени показа).
  С этого тика ульта «взведена» и срабатывает при первой возможности вне очереди хода (шкала действия обнуляется, как после
  хода): дальний — сразу, ближний — когда дошёл до цели. Касание неготовой ульты игнорируется.
- Сцена пересчитывает бой с тем же seed и всеми вводами и продолжает показ по новому логу с текущего места: префикс лога
  до момента ввода совпадает (ввод меняет только тики не раньше своего t; rng он не трогает) — тест
  `tests/battle-decisions.test.ts`.
- Кнопка «Авто» в бою переключает режим (ввод `{ t, auto: true|false }`); выбор запоминается (localStorage, настройка).
  Новый игрок начинает вручную. Авто всегда: «Пропустить» (остаток боя — авто), «Пропустить бой», «Авто: следующий
  этап», Башня и Охота (их экраны ведут другие задачи — ручной режим туда позже).
- Ввод передаётся в ядро через `BattleOptions.manualUlt / inputs` или `combat.player` (так сцена прокидывает его через
  `actPlayStage` без правок кампании): награды этапа считаются по тому же бою, что показан.

Как проверить: бой главы 1 — портреты светятся, касание — баннер ульты сразу; «Авто» — ульты сами. Тесты: детерминизм
с вводами, префикс лога, ручной режим держит ульту, авто без вводов = прежний лог.

## 2. Разведка перед боем

На экране этапа (StageScene) под полем — строка «Враги: …» по типам врагов: значок стихии + 1 особенность. Касание —
список целиком. Особенность выводится из данных (`src/core/elements.ts → enemyTraits`), не пишется руками:

- профиль `pack` — «стая», `coward` — «трус», `leaper`/`assassin` или навык с рывком в тыл — «прыгает в тыл»;
- лечащий навык или `basic_heal` — «лечит»; щиты союзникам — «ставит щиты»;
- навык по всем врагам / по площади — «бьёт по площади»; навык с кастом ≥ 1.5 с — «заряжает удар» (можно сбить);
- заряд босса (`charge`) — «заряд: сбейте ультой»; фазы — «призывает свиту» / «ярость».

## 3. Стихии (RO)

Защита врага — поле `element` у юнита (`neutral` по умолчанию); атака — поле `element` у навыка (Огненная стрела —
огонь, Святой свет — святость…), обычные атаки нейтральны. Таблица — `data/combat.json → elements.chart`:

- круг: огонь > земля > ветер > вода > огонь — ×1.5 по слабому, ×0.75 в обратную сторону;
- святость > нежить, тьма ×1.5; тьма > святость ×1.5; огонь по нежити ×1.5; тьма по нежити ×0.75;
- нейтраль без модификаторов. Герои защищаются нейтралью (стихии — инструмент игрока, а не наказание).

На экране: цветной кружок-значок стихии у врагов (разведка, бой — у полоски), «Слабость!» / «Стойкость» над целью —
не чаще раза в 6 с на цель. Без профилей поведения (`behavior: false`) стихий нет — снимки старых боёв не меняются.

## 4. Заряд босса («ответ»)

`units/<boss>.json → charge { skill, first, every }`: с `first` секунды и затем каждые `every` секунд после удара босс
начинает каст навыка `skill` (2.5 с, полоса каста + надпись «Заряд!»). Если за это время по нему попала ульта героя
(ручная или авто) или оглушение — «Сбито!»: каст пропал, босс оглушён на `combat.json → charge.stunTurns` (3 с). Не сбили —
тяжёлый удар по всему отряду (≈ 35–45% ОЗ героя при рекомендуемой силе). Ульта-одиночка героя, пока босс заряжает,
бьёт в него (сама выбирает цель). У всех 10 боссов глав — по заряду.

## 5. Профили монстров глав

Стаи, трусы, прыгуны, лекари — по `battle-behavior.md`; добавлены там, где их не было (см. balance.md).

## 6. Сложность

После всего — `scripts/balance-*.ts` один раз. Цель: босс главы в авто заметно тяжелее, ручная ульта в заряд — выигрыш;
темп (босс главы 10 ≈ день 19–21) не ломать. Итоги — `docs/content/balance.md`, раздел «Бой с решениями».
