### Открытые решения владельца
1. К 7-му дню ~5 фиолетовых вместо цели 2–3. Рычаги: зелёный→синий за 4 карты; меньше призывов в неделю; контракт в событии
   новичка заменить синей картой на выбор; или оставить (docs/content/balance.md, «Герои v2»).
2. Экспедиции: добавить срок 12 ч (игрок с 2 сессиями в день получает меньше гемов)?
3. Героев Биолаборатории (Альфоччо и др.) вернуть как облики/отдельных героев или оставить ветками 12 героев?
4. Подарок Таверны заметнее (окно «150 гемов + 10 свитков», «Свитки ×10 (есть N)») — предложено, ждёт ответа.

### Известные проблемы / следующие шаги
1. «Авто» (`autoFormation`) не гарантирует лекаря — иногда босс 1-10 проигрывается подряд; сделать «Авто» с лекарем, перепроверить баланс.
2. ch3_s10 — стена 12–48 ч; нужна смена состава ch3_s6–s9 (дизайн).
3. Глава 1 проходится за ~10 мин (цель 30–45) — больше этапов (контент-день), план — `docs/design/afk-gap.md`.
4. Арт: заказы `docs/ART_REQUEST_SKILLS.md` (эффекты навыков P1–P3, сокол охотника, тележка), `docs/ART_REQUEST_HEROES.md`
   (Грете нужен лист торговки `hero_greta_merchant`; облики веток в причёсках героев; иконка «Удар сковородой»).
5. Подсказка обучения на экране расстановки закрывает имена двух героев в ростере.
6. Потолок фиолетовых ур. 60 к 9-му дню и лишнее золото после него (см. выше) — решить с владельцем: больше фиолетовых копий
   поздно (Таверна/экспедиции глав 4–7), вознесение до золотого дешевле, или траты золота (снаряжение, лавка).
7. Экспедиции только до главы 3 (4 локации); локации глав 4–7 — вместе с правкой теста дневного бюджета (`tests/meta-expeditions.test.ts`).

### Как работать
- Работа → ветка `claude/idle-hero-rpg-gdd-rolicg` → PR в main → слить при зелёном CI → сбросить ветку на `origin/main`.
- Агенты — в worktree со строгим владением файлами; e2e на разных портах; vite не следит за `.claude/` под корнем checkout.
- Проверка перед PR: `npm run check`, `npm run e2e`, `npm run e2e:chapter1` (изредка падает из-за «Авто» без лекаря, см. выше).
