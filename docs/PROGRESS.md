### Плановая проверка каждые 30 минут
По просьбе владельца оркестратор ставит себе сообщение через `send_later` (delay_minutes: 30, initiation: human_request,
имя «Плановая проверка»). При каждом срабатывании он выполняет проверку и **заново ставит** такое же сообщение на +30 минут —
цепочка перевзводится каждым запуском (остановить — не перевзводить и удалить триггер, если владелец попросит).
Стандартный текст сообщения:

> Плановая проверка (каждые 30 минут, по просьбе владельца). 1. git fetch origin: если в main появились коммиты или арт владельца —
> слить main в claude/idle-hero-rpg-gdd-rolicg, подключить арт по docs/CONTENT_RECIPES.md (раздел 12), npm run check.
> 2. Проверить сабагентов: готовых — слить в рабочую ветку и проверить (check, e2e при изменении экранов); зависших — перезапустить
> с тем же заданием. 3. Открытые PR: CI зелёный — слить в main и сбросить рабочую ветку на origin/main. 4. Обновить docs/PROGRESS.md
> («Точка продолжения»). 5. Если есть новости — коротко написать владельцу простым текстом. 6. Поставить эту же проверку снова через 30 минут.
