- A — 19 профессий (tier 0–2), 88 навыков, проверки дерева профессий.
- B — кампания (глава 1, 10 этапов, монстры и босс на спрайтах v2), офлайн-награды.

- E — `npm run balance` (модель игрока, CSV, стены).

- G — ядро K1 быстрые награды, K2 мощь, K5 ежедневные задания, K7 пропуск; сохранение v2.
- I — K3 главы 2–3 (30 этапов), K4 башня испытаний (100 этажей по правилу).
- J — K6 экипировка (4 слота × 3 редкости, выпадение, надеть/снять), учитывается в бою кампании и башни.

- F — экраны: Главная с сундуком, кампания-тропа, подготовка этапа и отряд, бой этапа, итоги с наградами, герои, карточка, смена профессии.
- K — K8 пресеты и авторасстановка, K9 доска поручений, K10 достижения; сохранение v3.

- H, M — экраны всех функций K1–K10; L — баланс v2. Отчёт: docs/REPORTS/2026-09-26-night.md.

- N1 — единый сборщик контекста (buildGameContext); O — в dist только используемые ассеты (6.6 → 2.5 МБ), `npm run assets:report`.

- N2 — экран загрузки, читаемость боя, MVP, `npm run e2e`; P — единый вид экранов (theme.ts, русские статы, прокрутка, зоны нажатия); Q — фазз-тесты ядра (исправлен баг: погибший продолжал навык), проверка противоречий в сохранении.

- R — подсказки новичку, «Авто: следующий этап», прокрутка заданий, значок смены профессии; S — настройки за шестерёнкой, авторазмещение подсказок, полировка итогов.

- T — производительность боя (пулы, `npm run perf`): шаг Phaser 14.4 → 9.5 мс, JS за бой −31%.
- U — ленивая загрузка листов юнитов (текстуры: главная 193 → 15 МБ, бой 193 → 54 МБ), пауза при сворачивании, ограничение FPS 30/60.

- V — ревью кода: 4 бага исправлены с тестами; content:check гоняет героев всех профессий.

- W — задание «повышение уровня» считает уровни и от наград.
