# Приёмка компактного интерфейса

Telegram на телефоне 360×640 может занять 136 px сверху и 34 px снизу. Полное поле 1080×1920 при вписывании по высоте уменьшало текст до 10 px и кнопки до 32 px. Проверенные адаптивные сцены сохраняют ширину 1080, получают высоту 1410 и прокручивают содержимое отдельно от шапки и действий. Непроверенные сцены продолжают показывать полное поле; список находится в `supportsAdaptiveLayout`.

На момент первой приёмки зарегистрированы Кампания и Приключения. Другие экраны подключаются отдельными пакетами после браузерной проверки. Для новых экранов доступен dev-параметр `?compact=1`; production его не применяет.

## Повторить проверку

Используйте Node версии из `package.json` и уже установленный Playwright/Chromium. Скрипт запускает отдельные приватные browser contexts, пишет прогресс только в их localStorage, блокирует внешние запросы и все сетевые записи. Production URL запрещён. Устанавливать браузеры внутри репозитория не нужно.

```sh
npm run dev -- --host 127.0.0.1 --port 5511 --strictPort
```

В другом терминале:

```sh
URL=http://127.0.0.1:5511/ \
PLAYWRIGHT_MODULE=/путь/к/установленному/playwright \
CHROME_EXECUTABLE_PATH=/путь/к/chromium \
OUT=/tmp/chronoworld-compact-ui-qa \
node scripts/night-compact-ui-qa.cjs
```

По умолчанию последовательно проверяются WebGL и Canvas. `MODES=webgl1` принудительно отключает WebGL2. Если Playwright доступен через обычный `require('playwright')`, `PLAYWRIGHT_MODULE` можно не задавать; для браузера Playwright аналогично можно опустить `CHROME_EXECUTABLE_PATH`.

Для локальной production-сборки:

```sh
npm run build
npm run preview -- --port 5516 --strictPort
```

Затем тот же скрипт с `URL=http://127.0.0.1:5516/`. В приватном ответе compiled bundle скрипт добавляет диагностические ссылки на Phaser и текущую раскладку; файлы `dist` и сервер не меняются. Matcher явно завершает проверку ошибкой, если формат сборки изменился.

`report.json` содержит результат, SHA256 source/bundle, фактические сцены, размеры кнопок, текстов и scroll-масок, heartbeat renderer и ошибки. Снимки сохраняются рядом. Проверка не заменяет прохождение кампании: состояние выбора главы 3 создаётся из `newGame` с допустимыми полями прогресса и используется только в приватном контексте.

## Что проверяется

1. Холодное вступление: последний абзац достигается прокруткой; resize сохраняет открытую страницу; реальные «Далее» и «Пропустить» работают.
2. Реальные переходы Кампания → Приключения → Кампания → Этап → Бой → Итоги → Кампания → Приключения. Кнопки нажимаются через координаты экрана. Непроверенные сцены сохраняют высоту 1920.
3. Прокрутка баннеров и достижимость редактирования отряда; шапка и действия остаются в безопасной области; кнопки имеют не меньше 44 CSS px, основной текст — не меньше 12 CSS px.
4. Изменение высоты 640 → 760 → 640; поздние события Telegram safe area после `create`.
5. Открытый `ch3_rescue`: изменение высоты не выбирает ответ. Реальный выбор записывается один раз до показа reply; альтернативные кнопки удаляются.
6. Ни одной ошибки браузера, уничтоженной texture source или остановки renderer. Фактическое имя сцены проверяется после каждого перехода.

## Контракт адаптации

Используйте `view().uiHeight`, `view().safeBottom`, `contentBottom()` и `onViewChange(scene, callback)`. Прокручиваемое тело создаётся сразу, даже если первые отступы Telegram равны нулю. `ScrollArea.setBounds(top, bottom)` обновляет маску и ввод, сохраняет или ограничивает offset и отменяет текущий жест. Изменение высоты не должно перезапускать сцену, менять выбор героя, повторять награды или запускать новый бой.

Маска и `ScrollArea.parts` живут в координатах мира. Геометрические маски внутри движущихся баннеров должны следовать `getWorldTransformMatrix`; пример есть в `featureTiles.ts`. Размеры текста и интерактивных зон задаются в координатах мира с учётом `minimumFontSize`/`minimumTouchSize`. Одно растяжение камеры не адаптирует содержимое.
