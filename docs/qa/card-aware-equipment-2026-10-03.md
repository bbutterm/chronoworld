# Сравнение снаряжения с картами MVP

Основание: main `4517d116aaa2a8055a44f1986c9f4c26b0856757` (PR #123).

## Исправления

- Единый расчёт `heroItemStats` учитывает заточку и карту MVP для конкретного получателя; тот же расчёт используется в суммарных статах героя.
- Автоподбор сравнивает полный вклад экземпляра. Регрессия: замена предмета с картой не должна снижать мощь с 947 до 886.
- Обе ветки сравнения в инвентаре используют весовую формулу мощи. Смешанные изменения характеристик имеют нейтральный цвет, даже если мощь растёт.
- Полная строка сравнения переносится внизу карточки на всю ширину. Строки высотой 256 не скрывают отрицательные изменения за многоточием или кнопкой.

## Проверки

До публикации выполнены: контент, TypeScript, UI lint, полный набор 1422 тестов в 139 файлах, production build и `git diff --check`. Независимое ревью патча завершено.

Регрессии проверяют карты, заточку, зависимость от получателя, сохранение старого поведения без карты, весовую мощь и обе ветки сравнения. Тесты раскладки вызывают производственные функции с подменёнными консервативными метриками текста и отрисовкой. Это не проверка реальных пикселей Phaser.
