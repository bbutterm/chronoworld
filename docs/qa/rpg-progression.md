# Личный путь героя и безопасная тренировка

Пакет превращает развитие 12 карточек в путь постоянных персонажей. Копии сохраняют функцию повышения редкости и профессии; первый встретившийся экземпляр становится спутником. Новая сильная копия не должна автоматически заменять его или забирать его историю.

## Что меняется для игрока

- В разделе «Путь» видны личность героя, следующая конкретная цель, достигнутые вехи профессии и доверия.
- На уровне 10 открывается одна из трёх тренировок: «Стойкость» (+4% базовых ОЗ), «Точность» (+3% базовой атаки), «Прикрытие» (+6% базовой защиты). Выбор, смена и снятие специализации бесплатны. Бонусы не складываются и не умножают экипировку.
- Возврат тренировки бесплатен. Возвращаются оплаченные золото и общий опыт. Герой сохраняет id, редкость, выбранную профессию, экипировку, замок, близость и открытые записи. Подаренные догоняющие уровни остаются у героя и не создают ресурсный возврат.
- Освоенная ветеранская профессия, её вид и ульта сохраняются. Базовые характеристики и доступ к обычным навыкам зависят от текущего уровня; высокоуровневая выучка не работает на первом. Достигнутая другая ветка не даёт ветеранство новой ветке: каждой требуется собственный путь.
- Спутники, герои в отряде/пресете/экспедиции, закреплённые и обученные копии не идут в корм. Для обученной копии сначала нужно явно вернуть вложенные ресурсы и снять специализацию. Повышение самого спутника сохраняет его id.
- Всем 12 героям доступны личный разговор, собственное боевое испытание и совместный приём с другим персонажем. К пяти существовавшим цепочкам добавлены семь; прошлые id и старые выборы не меняются.
- Доверие за общий путь дополняет отношения из вечеров: по одному за достигнутые уровни 10/30/50, выбранную вторую профессию и золотую редкость. Максимум этой составляющей — 5, общей близости — 10. Поэтому герой, встреченный после завершения кампании, тоже получает доступ к личному развитию.
- Прогресс истории берётся из достигнутых пиков. Непрочитанное остаётся непрочитанным после сброса и смены профессии. Сюжетные замки по этапам кампании сохраняются.

## Персонажи и новые испытания

Ирис решает, как ответить ордену, который считает потерянный щит важнее вынесенных людей. Её испытание — провести отряд через желейные врата без потерь; совместный приём с Аланом помогает сохранить строй.

Кай восстанавливает сгоревшие книги и учится отвечать за результат без нового показательного пожара. Лира добивается авторства собственных защитных расчётов. Их задания связаны с безопасным проходом у оркского трона; приёмы друг с другом поддерживают урон и защиту.

Мэйлин учится искать белого волка вместе с отрядом, проверяя следы прежде, чем покидать дорогу. Её испытание — вывести всех из святилища Лунного цветка; Бран помогает проверять выбранные цели.

Отто восстанавливает тележку отца, сохраняя память в вещи, которая продолжает служить. В стоках он должен вернуть весь отряд с деталями; с Гретой они прикрывают доставку.

Тео учится слушать и давать короткий полезный сигнал вместо песни, заполняющей любую паузу. Его испытание возвращает потерявшихся у желейных врат; совместный приём с Викой поддерживает выживание.

Зара собирает проверяемые свидетельства против слухов и оставляет за собой право вести разговор. Её испытание — вернуться из боя у пирамиды, а не исчезнуть; Дорн обеспечивает окно для точного действия.

Разговоры не раскрывают поздние развязки кампании. Семь новых выборов сохраняются обычным способом в `tavern.choices`; повторное посещение не даёт новую близость. Новые испытания используют условия выживания, которые не привязаны к прежнему ускоренному темпу боя.

## Контракты сохранения

Все поля необязательны, версия сохранения остаётся 7:

- `HeroState.companion` — личный экземпляр героя; новые первые встречи выставляют его автоматически.
- `HeroState.training = {exp, gold}` — фактически оплаченная сумма. `levelUpHero` суммирует оплаты; `resetHeroLevel` обнуляет их одновременно с возвратом. Пять циклов «поднять → вернуть» дают нулевой прирост ресурсов.
- `HeroState.journey = {peakLevel?, branchLevels?, focus?}` — достигнутые уровни и выбранная выучка. Записи второй профессии используют стабильные id веток. Смена ветки запоминает прежнюю до записи новой.
- `SaveState.heroSeq` — последний выданный номер экземпляра. Слияние не уменьшает его; новый персонаж не наследует id удалённой копии и её экспедиционные отношения.
- Старые сохранения без `training` используют цену диапазона `grantedLevel → level` при первом действии. Новые оплаты хранятся точно и не меняются вслед за будущей правкой цен. Точную историю цен старых сохранений восстановить невозможно: в прежнем формате её не было.

Цены, порог и величины выучки лежат в `data/cards.json → training`, пороги доверия — в `data/story/tavern.json → bond.journey`. Схемы JSON перегенерированы. В детерминированном ядре нет системного времени или случайности.

## API интерфейса

- `heroJourney(save, heroId, ctx)` — личность, вехи, следующая цель, варианты выучки, источники близости.
- `heroResetInfo` / `resetHeroLevel` — предварительный расчёт / атомарный локальный возврат. Во время экспедиции оба изменения подготовки запрещены.
- `heroFocusOptions` / `setHeroFocus` / `clearHeroFocus` — просмотр / смена / снятие выучки.
- `openHeroJourney` и `openHeroTraining` — зарегистрированные листы с прокруткой, возврат ресурсов с подтверждением и точными суммами.
- `BondView.points` — общая близость с потолком; `tavernPoints` и `journeyPoints` — источники. `bondOf` сохраняет прежний контракт и возвращает только вечера.
- Спикеры `hero_<templateId>` показывают форму встреченного персонажа; неизвестный или невстреченный герой не получает портрет из ростера.

## Проверка

Автоматические регрессии покрывают обычные и подаренные уровни, повторные возвраты, точный ledger при смене цен, сохранение/загрузку, блокировку экспедиции, альтернативы выучки без накопления, защиту спутника и обученной копии, отсутствие повторного использования id, доверие без умножения копиями, замки невстреченных персонажей, непрочитанные записи и сюжетные ограничения. Для каждого из семи новых испытаний проверены проходимость сильным отрядом и однократность награды.

Целевые проверки: `npx vitest run tests/hero-journey.test.ts tests/heroes-core.test.ts tests/heroes-merge.test.ts tests/heroes-ascend-all.test.ts tests/heroes-summon.test.ts tests/hero-stories.test.ts tests/tavern.test.ts tests/tavern-badge.test.ts tests/story.test.ts`, `npm run typecheck`, `npm run content:check`.

Браузерная проверка объединённой сборки выполнена на 360×640 и 390×844: «Путь» и «Тренировка», смена специализации, отмена/подтверждение возврата ресурсов, Back в дочернем листе и reload. Результаты и просмотренные снимки — в [mobile-rpg-ui.md](mobile-rpg-ui.md); эта часть проверена настоящими нажатиями по canvas.
