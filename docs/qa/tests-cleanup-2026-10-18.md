# Чистка тестов 18.10.2026

Распоряжение владельца: «пройтись по всем тестам, уменьшить их число, но поднять качество». Это распоряжение снимает
запрет CLAUDE.md на удаление тестов только для удалений, перечисленных ниже; каждое удаление объяснено.

## Зачем

2 000+ узких тестов были зелёными, а тестер упёрся в то, что видно только на живом состоянии игрока (копии для
вознесения, непроходимая Башня). Узкие тесты проверяли не поведение, а реализацию: искали строки в исходниках сцен
(`readFileSync('src/game/scenes/X.ts')` + `toContain`/`toMatch`), закрепляли пиксели и значения токенов, повторяли друг
друга. Такой тест падает от безобидного рефакторинга и молчит, когда игрок не может сделать главное.

Теперь главный путь каждой механики проверяет `tests/smoke.test.ts` на настоящих сохранениях модели игрока (3, 7, 10 и
14 дней). Узкие тесты остаются там, где они проверяют поведение: правила ядра, формулы, сохранения и миграции, деньги,
жесты и раскладку через настоящие функции раскладки.

## Цифры

1. Файлы тестов: 245 → 241.
2. Выполняемые тесты vitest (с it.each и циклами): 2567 → 2207 (−360, −14%).
3. Строки it()/test() в исходниках: 2142 → 2052.
4. `npm run check` в этом контейнере: 132 с до, 133 с после (контейнер медленный и делит процессор с другими агентами;
   основное время — content:check и тяжёлые боевые тесты, их чистка не трогала).

Цель «−20…−35%» по числу тестов не достигнута сознательно: оставшиеся тесты поведенческие и уникальные, а резать их ради
процента владелец не просил («качество важнее количества»).
