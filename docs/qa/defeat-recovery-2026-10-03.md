# Советы после поражения: проверка выполнимости

Основание: локальная контрольная точка `191b8cf95b9131e38b411add8141230412914f9c`, соответствующая выпущенному PR #124.

## Воспроизведённые ошибки и исправления

1. Стартовый отряд, 5000 золота, 0 опыта и три запасные зелёные Ирис: совет предлагал вознести запасного героя, хотя в отряде есть пустые места. Теперь совет вознесения учитывает только выбранных героев. Общий список готовых к вознесению героев по-прежнему включает запасных; ограничение отрядом действует только на совет поражения.
2. Алан и Бран на уровне 20, Вика на уровне 1, нет ресурсов: совет утверждал, что опыт больше не усилит отряд. Следующий уровень Вики стоит 100 опыта и 15 золота. Теперь утверждение о пределе применяется только ко всем выбранным героям; частичный предел ведёт к существующему совету добыть ресурсы в кампании.
3. Все выбранные герои красные и на максимальном уровне: совет предлагал копии и вознесение, которого у них нет. Теперь предлагается проверить расстановку и сочетание навыков. Для остальных редкостей совет о копиях сохранён без обещания доступа к ещё закрытым Таверне и Лавке.
4. Совет вернуться в кампанию выделял плитку «Герои», ведущую в список героев. Теперь чужая плитка не помечается как совет; существующая кнопка «К кампании» не меняется.
5. Независимое ревью нашло пересечение кандидатов при переходе золотой → красный. Золотой Алан на уровне 80, 60000 золота, 0 опыта и только две фиолетовые копии (Алан и Ирис) ошибочно давали готовность: фиолетовый Алан считался одновременно в «та же» и «любая». Вместо повторного подсчёта групп используется существующий `ascendPlan`, выделяющий отдельные копии на каждый слот. Исправление готовности применяется и к совету, и к общему списку героев.

## Покрытие

- Точная граница доступности уровня по обоим ресурсам: хватает ровно, не хватает единицы золота, не хватает единицы опыта.
- Вознесение только запасных, сохранение глобального списка готовности; копии под замком, копии в отряде и отсутствие золота.
- Золотой → красный: две пересекающиеся копии не подходят; три отдельные свободные подходят; третья под замком или в отряде снова блокирует готовность.
- Частичный, полный и пустой отряд для предела уровней; максимальные уровень и редкость.
- Соответствие выделенной плитки действию совета при открытой и закрытой Таверне.
- Существующие тесты тактических фактов: завершённые заряженные атаки, подтверждённые прерывания, первый погибший лекарь и известный убийца, лечение врага при таймауте. Их логика не менялась.

## Проверки и ограничения

Окончательный проход после исправления пересечения копий: 46 целевых тестов в четырёх файлах и полный набор 1429 тестов в 139 файлах пройдены. Контент, TypeScript, UI lint, production build и `git diff --check` также пройдены. Предупреждения: прежние записи бестиария без встреч, отсутствующие листы для отдельных звуков; сборка предупреждает о разрешении путей шрифтов при выполнении и крупных JS-чанках.

Обёртка `npm run check` останавливается на создании IPC-сокета CLI `tsx` (`EPERM`). Для проверки того же исходного файла контента используется `node --import tsx scripts/content-check.ts`, затем обычные `npm run typecheck`, `npm test`; аналогично UI lint запускается через `node --import tsx scripts/ui-lint.ts`. Production build запускается стандартной командой.

Проверки логики выполняются без DOM. Это не визуальная проверка Phaser: реальные переносы и обрезка текста, кликабельность и возврат после повторной попытки в браузере не проверены. Геометрия плиток, маршрутизация сцен, баланс и детерминированное ядро не менялись. Текущий забег Башни возвращается в TowerScene и не проходит через этот экран поражения.
