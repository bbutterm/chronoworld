## Первичная остановка и точная коррекция helper

Исходный helper `6f2c2acf…` в первом public Canvas-проходе дошёл до фактического получения героя: **347 проверок, 16 фаз**, 0 ошибок или запрещённых запросов. На строгом сравнении после контракта он остановился. Stage и Squad этим первоначальным проходом не проверены. Его исходный FAIL сохранён и не переименован в PASS.

Независимая Node-реконструкция на точной базе main145 криптографически совпала с двумя реальными наблюдениями браузера. Два нормальных UI-коммита пропуска вступления главы 3 дали revision=2. Чистый `claimHeroPick` эту ревизию не меняет; `SaveSlot.write` повышает её ровно на 1. Добавление только ожидаемой revision=3 дало байтовое совпадение с реальным результатом браузера. Других отличий полей нет.

```sh

CHROME_EXECUTABLE_PATH=/usr/bin/chromium \
node scripts/night-packet3-native-qa.mjs \
  --root /workspace/chronoworld-worktrees/night-published-packet3 \
  --url https://chronoworld-ecru.vercel.app/ \
  --scope full --renderer canvas --width 360 --height 640 \
  --save "$PWD/docs/REPORTS/2026-10-05-packet3-production/fixtures/lawful-36.save.json" \

  --bundle-sha ee67ba54d6a6a48657c97fdc4289c0c41702cd685c00d2eb5e55d2099c89cd56 \

```

Для WebGL: `--renderer webgl --width 390 --height 844`. Для late: `--scope late` и сохранённые `fixtures/lawful-180.save.json` / `lawful-180.clock.json`. SHA другого deployment вызывает честную остановку; его нельзя игнорировать как успешную проверку этой версии.
