## Миграции и сохранность данных

Четыре файла из `supabase/migrations` применены по порядку одной транзакцией:

- `20260930000000_cw_baseline.sql` — исходная схема, индексы, RLS и права.
- `20261001120000_cw_bot.sql` — совместимая схема бота и расписание.
- `20261004130000_cw_reliability.sql` — CAS, журнал выдач и атомарный ACK.
- `20261004140000_cw_tower_week.sql` — отдельный недельный результат Башни.

В `supabase_migrations.schema_migrations` добавлены четыре соответствующие версии с исходным SQL.
История выросла с 27 до 31 записи; существующие записи не менялись.
CLI 2.119.0 требует TCP-проверку даже перед HTTPS-командой `db query`, а прямой PostgreSQL в среде
недоступен. Использован Management API по HTTPS с действующим CLI-логином через стандартный keyring.
Повторного входа, нового пароля БД и изменения сетевой политики не потребовалось.

Перед изменениями транзакция кратко заблокировала только таблицы `cw_*` и историю миграций.
Проверка количества строк и контрольных сумм содержимого выполнена внутри той же транзакции;
при отличии она отменяла бы всё обновление. Повторная проверка после COMMIT также дала совпадение:
три игрока, три сохранения, четыре записи рейтинга, три записи запуска бота; друзья и подарки пусты.
JSON сохранений, версии формата, главы и время записи сохранились. Новые поля `write_revision` /
`last_write_id` добавлены отдельно. Существующие дополнительные колонки не удалялись.

У восьми таблиц включён RLS, `anon` / `authenticated` не имеют прямого чтения или записи.
Пять RPC доступны `service_role`, закрыты для `anon` / `authenticated`; проверена сигнатура
`cw_sync_player` с девятым аргументом `p_tower_week`. Старый неоднозначный overload отсутствует.
Защитные ветки четырёх RPC выполнены от `service_role` для отсутствующего служебного ID в транзакции
с ROLLBACK: чтение вернуло пустое облако, запись/claim/sync — `no_player`. Данные игроков не использовались.

cron без секрета и с неверным секретом — 401. Последние проверки также проходят серверное чтение
`cw_config`, подтверждая доступ Edge Function к базе, без выдач и сообщений.
