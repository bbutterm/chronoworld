# Летопись на коротком Telegram viewport — 05.10.2026

Сценарий приёмки: игрок входит из Города в Летопись, просматривает пять каталогов, читает открытые записи, истории своих героев и уже увиденные сюжетные сцены, возвращается кнопкой Telegram «Назад», меняет размер окна и продолжает с прежнего места. Чтение не меняет ресурсы, отряд, прогресс кампании или личные пути героев.

## Собственный пакет

- `src/game/scenes/ChronicleScene.ts` — локальное переключение вкладок без перезапуска сцены; независимые позиции пяти списков; возврат из таверны и повторный вход из Города с сохранённым положением; обновление маски при resize. Названия и требования закрытых записей сохранены.
- `src/game/chronicleLayout.ts` — одна геометрия вкладок, счётчика и полосы списка. Цели касания от 44 CSS px, шрифт от 12 CSS px, список использует безопасную высоту вместо фиксированного полноэкранного низа.
- `tests/chronicle-compact.test.ts` — 13 проверок настоящих обработчиков сцены и геометрии; async-переход из нижнего листа, captured lock, stale hero callback, возврат через Город, resize и независимые offsets.
- `tests/fixtures/chronicle-legal-checkpoint.json` — неизменённый законный DATA2 checkpoint seed 3 после 180 этапов, 55 копий всех 12 героев. SHA256 `4cc658ebd5e3e26710efc40a4dda98cafa34e92ad4cf6ed62fc9f43bde1824fd`.
- `scripts/night-chronicle-ui-qa.cjs` — переносимая локальная приёмка настоящего Phaser: native touchscreen/drag, wheel, resize, SDK Back, каталоги и чтение. Внешние запросы и исходящие записи блокируются.

Сцена использует общие `loreModal`, `openHeroStory`, `showPages` и `openStoryHistory`; не создаёт их собственные копии и не регистрирует один modal повторно. `showPages` и история главы получают captured `ScrollArea` через `opts.lock`. Новый рассказ открывается только после завершения закрытия прежнего листа; его lock не освобождается запоздалым callback.

Маленькие подписи уже ограничивались глобальным `viewport.ts` при создании. Прежний шрифт `T.caption=34` сам по себе не доказательство ошибки: глобальный factory повышает его до минимума. Здесь исправлена геометрия и состояние сцены; снижение глобального порога или новый общий UI helper не требуется.

## Доказательства

Изолированная база — `41bbcc0718060d11d64248c8d2c0028177eae785`. На её неизменённом `ChronicleScene` тот же набор 13 тестов даёт 9 FAIL / 4 PASS; после изменений — 13 PASS. Нет `.skip`, `.only`, изменения старых порогов или перезапуска сцены ради успешного assertion. Typecheck и `ui:lint` проходят. Исходная сцена для baseline временно импортировалась отдельным тестом, затем оба временных файла удалены.

Предварительная native Canvas 360 проверка нового экрана: 109 снимков состояния, 38 открытых карточек, все пять вкладок, настоящее движение пальца, resize, SDK Back и возврат из таверны — PASS. Она сохранена отдельно от финального compiled прогона; её старые hashes не выдаются за hashes последующего source.

Финальный полный прогон: Canvas fresh — 203 состояния PASS, Canvas legal — 1605 PASS, WebGL fresh — 203 PASS. WebGL legal проверил 1594 состояния, все 244 детали, 12 историй, 75 сюжетных повторов и 20 страниц, затем остановился на дополнительном переходе к Алану. Этот полный прогон сохраняет `passed:false`, а не объявляется 4/4 PASS.

Причина остановки соответствует недостающей синхронизации QA: после `SDK Back` скрипт ждал фиксированные 300 ms. `screen.ts:popOut` уничтожает окно по окончании игрового tween, а защита от следующего тапа начинается на DESTROY; `input.enabled` до этого события ещё может быть true. Последующий тап по вкладке попал в фазу закрытия, вкладка осталась «Мир». Теперь скрипт ждёт реального отсутствия `screenModal` и окончания защиты, с прежним пределом 10 s. Продукт не изменён.

Отдельный короткий native WebGL legal tail прошёл 7 состояний: chapter-detail → SDK Back → фактическое закрытие → «Герои» → Алан → повторное открытие истории → закрытие. Полный JSON и ревизия совпали до/после; новый commit не появился. Setup воспроизводит только 12 публичных `markHeroStoryRead` / `SaveSlot.write` предыдущего пути чтения на том же законном checkpoint, без новых побед, ресурсов или уровней. Все три полных PASS, исходный WebGL STOP и отдельный tail PASS сохранены с собственными hashes в `night-chronicle-compact-2026-10-05.summary.json`; вся матрица после tail не повторяется.

Законный checkpoint содержит 75 действительно увиденных сцен. В первой главе их 7: модель полного прохождения читала `afterStage`, но не вступление/`beforeStage`. Приёмка проверяет все 75 реально увиденных сцен и все 12 историй полученных героев; не приписывает сохранению 13 прочитанных сцен первой главы. Свежая игра проверяется отдельно с настоящими закрытыми записями.

Проверка сравнивает полный JSON сохранения с независимо рассчитанным публичным контрактом чтения, включая `heroStoryRead` и `revision`. Для заранее известных доступных историй Node вызывает `heroStoryUnread` / `markHeroStoryRead` и публичный `SaveSlot.write` в памяти: ровно одна ревизия за героя с новыми открытыми кусочками, ни одной при повторном чтении. На свежем fixture это 0 записей, на законном — 12. `seenScenes`, сюжетные решения, ресурсы, копии, companion journey, снаряжение, отряд, задания и награды вечеров должны совпасть. Читать старый выбор не значит выбрать или получить награду ещё раз.

Первый compiled прогон остановился после полного Canvas checkpoint на строгом сравнении сохранения: старая проверка не учитывала номер ревизии 12 → 24 от этих 12 read commits. Она не объявлена успешной; исходный отчёт с `passed:false` сохранён в `/tmp/chronoworld-night-chronicle-compiled-final/report.json`. Все 244 детали, 12 историй, 75 сюжетных повторов и 20 страниц до этого прошли. Исправлен только ожидаемый контракт переносимого QA, ни одно поле больше не исключается и продукт не меняется. Последующий полный прогон имеет отдельный путь и hash в summary.

## Воспроизведение

```sh
VITE_CONFIG_NATIVE_IGNORE_WARNING=true npm run build
VITE_CONFIG_NATIVE_IGNORE_WARNING=true npm run preview -- --host 127.0.0.1 --port 5554
```

Во втором терминале, после read-only overlay зависимостей из summary:

```sh
URL='http://127.0.0.1:5554/?compact=1' \
COMPILED=1 \
PLAYWRIGHT_MODULE=/opt/codex/runtimes/cua/lib/node_modules/playwright \
CHROME_EXECUTABLE_PATH=/usr/bin/chromium \
OUT=/tmp/chronoworld-night-chronicle-compiled-final \
node scripts/night-chronicle-ui-qa.cjs
```

Скрипт запускает четыре контекста последовательно: Canvas360 и WebGL390, свежая игра и законный checkpoint. Можно выбрать один контекст через `MODES=canvas FIXTURES=fresh`. Playwright/Chromium в репозиторий не устанавливаются. `URL` разрешён только локальный; отсутствие compiled hooks при `COMPILED=1` — ошибка, без тихого перехода на dev или другой renderer.

Короткий проблемный переход: `MODES=webgl FIXTURES=legal TAIL_ONLY=1` с отдельным `OUT`. Этот режим не заменяет полный прогон и не меняет его исходный `passed:false`.
