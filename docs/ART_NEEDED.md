# Недостающая графика

Собрано 27.09.2026 по коду, данным и `npm run assets:report`. Всё, чего нет, сейчас рисуется заглушкой — игра работает. Как подключать: спрайты юнитов — `docs/SPRITE_SPEC.md` (формат v2, `assets/sprites/sprites.json`); остальное — PNG в `assets/` + запись в `assets/manifest.json` по id (код не трогать).

## Требования (коротко)

PNG с прозрачностью; спрайты — по `docs/SPRITE_SPEC.md` (родной масштаб, вправо, ноги в одной точке, без теней, лист ≤ 2048 px); фоны 1080×1920; иконки квадратные. Проверка после добавления: `npm run content:check` и `npm run assets:report`.
