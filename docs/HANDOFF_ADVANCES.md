## Что реализовано

- 13 сигнатурных навыков адвансов, с адаптированными под текущее ядро механиками; стабильные ID старых навыков сохранены.
- Pressure (`ro_paladin_pressure`): offensive-урон с обходом DEF и снятие 35 энергии у цели, не защитный бафф.
- 24 продвинутые формы наследуют навыки первой/второй профессии. Пороги: золото 70/80, красная карточка 90/100. Личные ульты сохранены.
- Канонический предпросмотр веток рассчитывает активную форму по редкости/уровню получателя. Показывает продвинутые спрайт/профессию/ульт, но верстка НЕ принята.
- Восемь исходных стихийных RO cast-sheet зарегистрированы; подбор по навыкам участвующего отряда, общий проектор элемента для loader/playback. При загруженном sheet скрываются дублирующие процедурные круги/моты.
- Песочница compile-gated: `VITE_ADVANCE_LAB=1`. Обычная сборка без флага должна оставаться обычной игрой. Подготовлены 24 формы уровня 100, раздельные сохранения/настройки; online/API для песочницы отключены; сброс восстанавливает тестовый ростер.
- Публичный статический тест: https://85.137.93.201:8443/advance-lab/ . Не путать его с основной игрой.

## P0 — мобильный UI забагован / перегружен (зафиксировано, НЕ исправлено)

Источник: присланный владельцем скриншот окна «Сменить ветку», iPhone Safari. Исходник вне Git: `/root/.hermes/cache/images/img_77a1299d2710.jpg`.

Конкретные видимые дефекты:
1. Слишком много текста для двух узких карточек: статы, лор, цепочка профессий, редкости/пороги, инструкция, сигнатура и ульт конкурируют на одном экране.
2. «12 навыков · коснитесь навыка: подробнее» слева и аналогичный блок справа НАЕЗЖАЮТ на первые строки сигнатурных навыков `Spiral Pierce` / `Pressure`; иконка, заголовок и строки описания визуально смешаны.
3. Длинный курсивный лор занимает множество строк и обрезается многоточием, мешая быстрому сравнению.
4. Спрайты/оружие выходят выше верхней рамки карточек, в область вводного текста; плашки «Выбрано»/«Сейчас» лежат поверх изображений.
5. Плотность и визуальная иерархия неудовлетворительны: много мелкого текста, несколько конкурирующих стилей и RU/EN названий, ключевые различия не считываются.
6. Внизу карточек при этом остается значительное пустое пространство: проблема не просто в нехватке общей высоты, а в распределении и пересечении блоков.

Связанные файлы: `src/game/branchPicker.ts`, `src/game/scenes/HeroScene.ts`, `src/game/skillFacts.ts`, shared UI helpers. Нужен отдельный согласованный проход упрощения/верстки и реальные mobile screenshots до/после. Не лечить изменением только текста/счетчиков тестов. До нового разрешения — только учет дефекта.
