## Коротко для художника (скопировать в мессенджер)

```
Нужны спрайты монстров Ragnarok Online для глав Chronoworld и фоны глав.
Монстры: листы v2 строго по docs/SPRITE_SPEC.md (класс monster: клетка 240x224, якорь 100,120, 5 анимаций, смотрят вправо, x1, без тени). Класть в assets/sprites/monsters/<id листа>.png и добавлять запись в assets/sprites/sprites.json (обычно tools/build_sprites_v2.py --only <id>). Если монстр не влезает в клетку monster — класс boss (256x256).
Список: docs/ART_REQUEST_CHAPTERS.md (id листа, монстр RO и его номер в mob_db).
Порядок: боссы без своих листов (Орк-лорд, Смотритель часовой башни, Владыка мёртвых), затем главы 2, 3, 7, потом 4–6, 8, 10.
Фоны: assets/backgrounds/bg_battle_ch<N>.jpg и bg_map_ch<N>.jpg, N — номер главы на маршруте (2 канализация, 3 орки, 7 часовая башня, 8 Гласт Хейм, 10 Нифльхейм и т. д.), 720x1280 (или 1080x1920), jpg. На фоне боя центр по высоте (примерно 45–95% высоты) спокойный — там стоят бойцы; карта — место под извилистую дорожку из 18 кружков-этапов.
```
