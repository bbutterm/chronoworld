# Заказ арта: монстры и фоны глав 4–7 (и два монстра главы 1)

Главы 4–7 играются уже сейчас: у 24 новых монстров стоят листы-заплатки (чужой лист RO, перекрашенный через `visual.tint`),
фоны нарисованы кодом (`src/game/backdropsExtra.ts`). Арт заменяет заплатки — игра не ждёт.
Боссы глав уже со своими листами: Осирис (`osiris`), Лунный цветок (`moonlight_flower`), Дрейк (`drake`), Тёмный лорд (`dark_lord`).

## Коротко для художника (скопировать в мессенджер)

```
Нужны спрайты 24 монстров Ragnarok Online для глав 4–7 Chronoworld и 8 фонов.
Монстры: листы v2 строго по docs/SPRITE_SPEC.md (класс monster: клетка 240x224, якорь 100,120, 5 анимаций, смотрят вправо, x1, без тени). Класть в assets/sprites/monsters/<id листа>.png и добавлять запись в assets/sprites/sprites.json (обычно tools/build_sprites_v2.py --only <id>). Если монстр не влезает в клетку monster — класс boss (256x256).
Список: docs/ART_REQUEST_CHAPTERS.md (id листа, монстр RO и его номер в mob_db).
Порядок: глава 4, потом 5, 6, 7.
Фоны: assets/backgrounds/bg_battle_ch4.jpg … ch7 и bg_map_ch4.jpg … ch7, 720x1280 (или 1080x1920), jpg. На фоне боя центр по высоте (примерно 45–95% высоты) спокойный — там стоят бойцы; карта — место под извилистую дорожку из 10 кружков-этапов.
```

## Фоны

Файлы побеждают нарисованные кодом сами (glob в `src/game/backdrops.ts`), регистрации не нужно:
`assets/backgrounds/bg_battle_ch<N>.jpg` и `bg_map_ch<N>.jpg`, N = 4…7.

1. Глава 4 — пустыня Сограт: дюны, пирамиды в мареве, обломки колонн, пальмы оазиса.
2. Глава 5 — лес Пайона ночью: сосны и бамбук, луна, каменные и бумажные фонари, светлячки.
3. Глава 6 — затонувший корабль: толща воды с лучами сверху, палуба/трюм, мачты, водоросли, пузырьки.
4. Глава 7 — Нифльхейм: фиолетовое небо, замок Тёмного лорда вдали, мёртвый лес в тумане, надгробия, голубые огни.

После: `npm run assets:webp` (WebP для прод-сборки), `npm run content:check`, `npm run assets:report`.
